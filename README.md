# 💸 Expense Tracker – iOS App

An all-in-one iOS application to help users track their expenses, manage income, set financial goals, and learn personal finance basics.

📁 **Access the full project files here:**  
[Google Drive Link](https://drive.google.com/drive/folders/1XKFkTi8nx74Bo7eO9nnmjroLRsNJKeoQ?usp=drive_link)

---

## 🚀 Features

- 📊 Add and manage expenses, savings, taxes, income, and investments  
- 🎯 Set financial goals and monitor progress  
- 📚 Learn personal finance concepts through integrated video modules  
- 📰 Stay updated with financial news  
- 👤 Register and manage your profile easily  

## 🛠️ Built With

- Swift  
- UIKit  
- Xcode  
- MVC Architecture  
- AVKit (for video playback)
